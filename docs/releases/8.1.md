## What's new


### Other features

 * Only auto-create redirects when moving or renaming live pages, not draft; use `WAGTAILREDIRECTS_AUTO_CREATE = 'always'` to restore previous behaviour (Sage Abdullah)
 * Show allowed file types as part of document upload form help text (Bhavesh Sharma)

### Bug fixes

 * Avoid redundant writes back to the cache on `get_rendition` and `get_renditions` (Mason Lyons, Matt Westcott)
 * Allow `ChooserBlock.bulk_to_python()` to resolve records with primary keys that need converting to their native type, such as UUIDs (Saksham Chawla)
 * Prevent error when accessing the sitemap via an unknown host and no default site is configured (Jawad Khan)
 * Fix excessive memory usage when copying a page with many revisions (Taras Panasiuk)
 * Prevent nested submenu labels from becoming invisible when using the slim sidebar (Neda Gilanian, Sage Abdullah)
 * Prevent memory exhaustion through over-long inputs to `get_supported_content_language_variant` (Matt Westcott)
 * Use `add_unredirected_header` to pass authorization headers to Facebook/Instagram embed APIs (Matt Westcott)
 * Prevent failures when instantiating form pages within migrations (Satyam Laheri)
 * Fix audit log actions for copy, copy-for-translation and create-alias to log the page being copied rather than its parent (Waqas Ahmed)
 * Respect EXIF orientation on avatar uploads (Damien Meur)
 * Improve performance of `instances_user_has_any_permission_for` and `explorable_instances` in `PagePermissionPolicy` (Ayush Kumar)

### Documentation

 * Fix broken links to Cloudflare and Handsontable documentation (Roshan Ramani)
 * Update generative AI policy to require pull request descriptions to be human-written (Matt Westcott)
 * Fix documentation for `wagtail_update_image_renditions` command to correctly describe behaviour around purging of renditions (Saksham Chawla)

### Maintenance

 * Drop support for Python 3.10
 * Remove obsolete use of `USE_L10N` setting (DresdenGman)
 * Squash testapp migrations (Sage Abdullah)
 * Use `format_html` for submit translation form help text (Keerthi Kumar)
 * Add testing section to PR template (Srishti Jaiswal)
 * Remove jQuery usage in ExpandingFormset (Keerthi Kumar)
