## What's new

### Bug fixes

 * Prevent duplicate meta schemas for models used in foreign keys (Sage Abdullah)
 * Generate best-effort schema for API v3 `APIField`s with a custom serializer that has type hints on `to_representation` (Sage Abdullah)
 * Prevent API v3 PATCH requests from discarding unpublished draft changes of live pages and snippets (Sage Abdullah)
 * Correctly handle tags passed as a list of names in API v3 write requests (Sage Abdullah)
 * Respect submitted order of child relation items in API v3 write requests (Sage Abdullah)
 * Respect custom primary keys in API v3 write schema for inline panels (Sage Abdullah)
 * Fix child relations with `related_query_name` or default accessor being ignored by API v3 (Sage Abdullah)

### Maintenance

 * Suppress warnings generated under sphinx-llm 1.1.0 (Matt Westcott)
 * Fix erroneous workflow creation test failing on Django 5.2.18 / 6.0.9 / 6.1.2 (Sage Abdullah)
